# CTG Rush

**চট্টগ্রাম · বন্দর নগরী** — an open-world 2D driving game set in a Chittagong-style port city. Runs in any web browser, no install needed.

Drive the Port City. Take jobs. Earn taka. Don't get caught.

## How to play

Open `index.html` in Chrome (double-click it). That's it.

| Key | Action |
|---|---|
| W A S D / arrows | Drive / walk |
| E | Get in / out of a vehicle (or board the train) |
| Space | Handbrake |
| Shift | Run (on foot) |
| H | Horn |
| M | City map (drag to move, scroll to zoom, click to set a waypoint) |
| P | Pause |

## Features

- **Vehicles:** CNG auto-rickshaws, cars, buses, trucks, motorbikes, rickshaws, ambulance, speedboats, a plane you can fly, and a train with 3 stations.
- **Jobs:** drive to a green ৳ marker, pick up a passenger or parcel, deliver before time runs out. CNG (+30%) and rickshaw (+50%) bonuses on passenger jobs.
- **Police:** crimes give wanted stars — escape the police or get busted.
- **Places:** Agrabad, GEC Circle, New Market, Reazuddin Bazar, CRB, Chittagong Medical College, Shah Amanat Airport, Patenga Beach, Port Gate, Karnaphuli Bridge, Link Road, Sholoshahar Station, Foy's Lake and more.
- **Maps:** corner minimap with place names, and a movable, zoomable city map with waypoints.

Made with plain HTML5 Canvas and JavaScript — a single file, no libraries.
